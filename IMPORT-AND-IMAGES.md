# Importing products and adding pictures

## Import products from Excel or CSV
Back Office → **Products → Import**.

1. Choose an Excel (.xlsx, .xls) or CSV file. No file yet? Use **Download the Excel template**.
2. Check the **Match your columns** step. Columns are matched automatically; if a heading isn't recognised, pick the
   right column from the list. Only **Product Name** is needed — Category, Price, Cost and Stock are optional.
3. Read the summary (how many are ready, what will be skipped and why) and the preview, including the **product
   code** each product will get.
4. If you have several shops and the file has stock, choose **which shop receives the stock**.
5. Press **Import**.

Good to know
- A product code is created for every product (a code in your file is kept if it is free).
- A product whose **name already exists** is skipped, never overwritten.
- Unreadable prices/costs/stock become 0 and are counted in the summary.
- If the file has no heading row, untick "The first row contains column headings".

## Product pictures
Products → add or edit a product → under the picture box. Every picture is shrunk automatically so it can't slow down your data, and its credit is saved with it.

**Bring a picture in**
- **Upload** — click the box, or **drag** a picture onto it, or copy any picture and press **Ctrl+V** on the form.
- **Find a picture online** — searches free-to-use pictures **at once** from Open Food Facts, Open Beauty Facts, Open Pet Food Facts, Open Products Facts and Wikimedia Commons.
  - If the product has a **barcode**, the finder first shows the **exact product** ("Exact barcode match").
  - It also tries a simpler wording of the name (without sizes like 500ml) when the first finds little.
  - **Show more pictures** goes further through every source. **Also search Openverse** adds free-to-reuse pictures from many other sites (it allows only a few free searches an hour, so it runs only when you ask).
  - Filter the results by source with the buttons above the pictures.
- **Paste a picture's web address** in the finder to bring in a picture from any website.
- **Google / Bing / DuckDuckGo** buttons open an image search in a new tab. Right-click a picture → **Copy image**, then press **Ctrl+V** on the picture box (or drag it onto the box).

**Stock-photo libraries (optional).** In the finder, open "Search stock-photo libraries too" and paste a free key for **Pixabay**, **Pexels** and/or **Unsplash**. Get a key by making a free account with that library. Keys are kept **on this device only**.

**"That picture couldn't be downloaded"** — many websites don't let other sites copy their pictures. Press **Try another way** (it asks the free image service **wsrv.nl** to fetch the picture; it is sent only the picture's web address, nothing about your business), or save the picture and **Upload** it, or copy it and **Ctrl+V**.

**About rights.** Pictures from the free-to-use libraries are licensed for reuse and AUREUM keeps the credit. Pictures from ordinary websites (pasted, dragged or via a web address) are usually copyrighted — use only pictures you have the right to use.

Press **Save product** to keep the picture.

## Product codes
Every product always has a code. Leave the box as it is (or clear it) and one is generated. Two products can't
share a code. Products that had no code get one automatically when the Back Office opens.
